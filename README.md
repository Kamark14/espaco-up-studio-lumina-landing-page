# Studio Lumina — Landing Page

Landing page responsiva criada como demonstração comercial para o Studio Lumina / Espaço UP.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro
- Google Fonts
- Font Awesome

## Recursos
- Design editorial branco + dourado
- Responsivo para desktop, tablet e celular
- Menu mobile
- Galeria com lightbox
- CTAs de WhatsApp
- Instagram
- Mapa do Google
- Animações de entrada
- Imagens locais na pasta `assets`

## Abrir
Abra `index.html` no navegador ou em Vercel/GitHub Pages.
